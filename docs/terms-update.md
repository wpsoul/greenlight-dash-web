# Proposed update to https://greenlightdash.pro/terms-and-conditions/

The current page describes a free browser version and a paid desktop application. With
GreenLight Dash Server the offer changes to: a **free desktop app with PRO-gated
features**, and a **self-hosted server edition under the same licence**. Suggested text
to replace or extend the existing sections (keep your company name, refund policy and
the clauses that stay true).

## Product delivery

GreenLight Dash is available as a free desktop application (macOS, Windows, Linux) and
as a self-hosted server edition ("GreenLight Dash Server") that you install on your own
infrastructure. Some features in both editions require a PRO licence. Paid access is
delivered after payment verification, which may take 1–24 hours.

GreenLight Dash is proprietary software and is licensed to you, not sold. You receive a
non-exclusive, non-transferable licence to install and use the software on your own
devices and servers. A PRO licence key may be activated on the number of devices stated
at purchase. **For the server edition, one server installation, identified by its
domain name, counts as one device.** Moving the installation to another domain uses
another activation; deactivate the old one first from the server's licence command.

Redistribution, reselling, sublicensing, renting, or offering the software (including

## Your content

You retain all rights to the media, boards, projects and other content you create,
import or generate. The desktop edition keeps files on your device; the server edition
keeps them on your server. We do not receive, store or process your content.

## Third-party services and keys

Image, video and audio generation, transcription, the AI agent runner, sharing and
collaboration use third-party services (AI providers, Anthropic, Cloudflare) with **your
own accounts and keys**. Your use of those services is governed by each provider's terms
and you are responsible for their costs, for the outputs, and for keeping your keys safe.
On the server edition, keys and tokens you configure are stored on your server only.

## Server edition responsibilities

You are responsible for the server you run the software on: keeping it updated, backing
up its data directory, placing it behind TLS, and controlling who has the owner password
and API tokens. We provide the software and its documentation; we do not operate,
monitor or secure your server.

## Anonymous install statistics

The server edition sends a small anonymous message once a day (a hashed identifier of
its domain, the software version, the profile, whether a licence is active, and the
operating system) so that we know how many installations exist. It never contains your
content, hostnames, keys or tokens. You may switch this off with the `GL_TELEMETRY=0`
setting.
